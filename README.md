# Growth OS — Agent Command Center

Your 7-agent marketing dashboard for your local web design business.

## Setup (one time only)

**Step 1 — Install Node.js**
Download and install from https://nodejs.org (choose the LTS version)

**Step 2 — Open this folder in terminal**
- On Mac: right-click the folder → "New Terminal at Folder"
- On Windows: open the folder, click the address bar, type `cmd` and hit Enter

**Step 3 — Install dependencies**
```
npm install
```

**Step 4 — Start the app**
```
npm run dev
```

**Step 5 — Open in browser**
Go to http://localhost:5173

---

## Daily use (after setup)

Just open terminal in this folder and run:
```
npm run dev
```
Then go to http://localhost:5173

Your chat history and task checkboxes save automatically to your browser and persist between sessions.

---

## What's inside

- **Overview** — all 7 agents with progress bars and quick-launch buttons
- **Tasks** — daily and weekly tasks per agent, checkboxes that save automatically
- **Chat** — talk to any agent directly, history persists between sessions
